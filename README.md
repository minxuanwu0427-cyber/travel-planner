# 出國旅遊行程規劃網站

純 HTML/CSS/JS 靜態網站，電腦、手機皆適用，無需任何建置流程。

## 檔案結構

- `index.html` — 網站入口
- `styles.css` — 樣式（含響應式設計）
- `app.js` — 所有邏輯與互動
- `firebase-init.js` — Firebase 連線設定（匿名登入 + Firestore）
- `default-images.js` — 沖繩範例行程的預設封面照/路線圖（base64，僅在資料庫第一次初始化時用來寫入種子資料）
- `lucide.min.js` — 圖示庫（本地版本，離線也能顯示圖示）
- `manifest.json` — PWA 設定檔，讓「加入主畫面」後能像 App 一樣全螢幕開啟
- `icons/` — App 圖示（用你提供的插畫裁切成方形，各尺寸皆有）

## 加到手機主畫面（像 App 一樣使用）

**iOS（Safari）**：開啟網站 → 分享按鈕 → 「加入主畫面」。圖示會自動用你提供的插畫（已裁切成方形），打開後會全螢幕顯示，看不到網址列。

**Android（Chrome）**：開啟網站 → 右上角選單 → 「加到主畫面」或「安裝應用程式」。

> 這個全螢幕效果需要透過網址（部署後的 https 網址）開啟並加入主畫面才會生效，直接在電腦上打開本機的 index.html 檔案不會有這個效果。

## 本機預覽

直接用瀏覽器開啟 `index.html` 即可，不需要啟動伺服器，但需要能連上網路（因為要連 Firebase）。

## 部署到 Vercel（跟你之前的習慣一樣）

1. 把這個資料夾整個推到一個新的 GitHub repo
2. 到 Vercel「Add New Project」→ import 這個 repo
3. Framework Preset 選 **Other**（純靜態網站，不需要 build command）
4. Output directory 留空或填 `.`
5. Deploy

## 資料儲存說明（已改用雲端資料庫 Firestore）

- 所有行程資料（航班、行程項目、預算、備忘錄）跟照片都即時同步存在 Firebase Firestore 雲端資料庫，不是存在瀏覽器本機了。
- 任何旅伴打開網站看到的都是同一份最新資料，一個人改了，其他人畫面會即時更新（不用重新整理）。
- 換裝置、清瀏覽器快取都不會遺失資料。
- 「你是哪位旅伴」這個身份選擇，還是存在自己裝置的瀏覽器裡（因為這只是個人化顯示用，不是共用資料）。
- 資料庫第一次啟用時（完全空的時候），網站會自動把範例行程（沖繩、釜山）寫進去當作起始資料；之後就不會再重複寫入。

## 已知限制

- 目前是「有連結就能編輯」的輕量共享模式（匿名登入，沒有真的帳號密碼），適合朋友之間規劃行程用；如果之後需要更嚴謹的權限控管，需要再加上正式的登入系統。
- 圖片存在 Firestore 資料庫裡，單張圖片有 1MB 的大小限制（目前上傳時已經自動壓縮，正常使用不會遇到）。
