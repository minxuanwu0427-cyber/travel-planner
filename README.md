# 出國旅遊行程規劃網站

純 HTML/CSS/JS 靜態網站，電腦、手機皆適用，無需任何建置流程。

## 檔案結構

- `index.html` — 網站入口
- `styles.css` — 樣式（含響應式設計）
- `app.js` — 所有邏輯與互動
- `default-images.js` — 沖繩範例行程的預設封面照/路線圖（base64）
- `lucide.min.js` — 圖示庫（本地版本，離線也能顯示圖示）

## 本機預覽

直接用瀏覽器開啟 `index.html` 即可，不需要啟動伺服器。

## 部署到 Vercel（跟你之前的習慣一樣）

1. 把這個資料夾整個推到一個新的 GitHub repo
2. 到 Vercel「Add New Project」→ import 這個 repo
3. Framework Preset 選 **Other**（純靜態網站，不需要 build command）
4. Output directory 留空或填 `.`
5. Deploy

## 資料儲存說明

- 所有行程資料（航班、行程項目、預算、備忘錄等）與上傳的照片都存在瀏覽器的 `localStorage`，重新整理頁面不會消失。
- 這代表資料是「存在使用者自己的瀏覽器裡」，換裝置或清瀏覽器快取會遺失資料，且無法真正跨裝置同步（旅伴間的「分享連結」目前是原型示意，實際上還沒有後端可以同步資料）。
- 如果之後想要真正多人即時同步，會需要接一個後端（例如 Firebase / Supabase），這部分我還沒做，可以之後再繼續加。

## 已知限制（沿用原設計，尚未實作）

- 分享連結目前只是產生一個網址字串，實際點開不會真的帶出該行程（因為沒有後端）
- 圖片只存在本機瀏覽器裡，不會同步給其他旅伴看到
